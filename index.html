📲 Cách Cài Đặt Lên iPhone (iOS)

⚠️ Lưu ý quan trọng về hệ điều hành iOS: Apple không cho cài file IPA bằng cách nhấn mở trực tiếp như file APK của Android. Dưới đây là 2 cách tối ưu nhất:

1
Cách 1: Cài trực tiếp từ Safari trong 5 giây (PWA - Khuyên dùng):
Mở trang web này trong trình duyệt Safari trên iPhone -> Bấm nút Chia sẻ (Share ⬆️) -> Chọn "Thêm vào Màn hình chính" (Add to Home Screen). Ứng dụng sẽ có icon riêng ngoài màn hình, chạy toàn màn hình và gửi thông báo y hệt app gốc!
2
Cách 2: Cài bằng File IPA (Sideloading):
Cần dùng công cụ ký chứng chỉ miễn phí như Sideloadly, AltStore hoặc TrollStore trên máy tính kết nối cáp với iPhone để nạp file .ipa vào máy.
3
Cách 3: Tự động Build IPA qua GitHub Actions:
Chúng tôi đã tạo sẵn mã nguồn Swift hoàn chỉnh và file CI/CD build-ipa.yml. Bạn chỉ cần đẩy lên GitHub là máy chủ macOS của GitHub sẽ tự xuất file .ipa thật cho bạn tải về!
